------------

功能:
  1. 使用 Python 标准库 socket 建立到 M8190A 的原始 TCP 连接（与 MATLAB tcpclient 行为一致）。
  2. 完整复现 xfprintf / xquery / xbinblockwrite 三个底层 SCPI 通信函数。
  3. 复现 makeArbConfig + loadArbConfig，构造 M8190A_12bit 模式所需的 arbConfig。
  4. 复现 readFile / loadfile 对单列 txt 波形的读取、归一化、重复次数计算。
  5. 复现 download / download_M8190A / gen_arb_M8190A / doRun 的完整下载流程：
     - 自检 :TEST:PON?
     - 设置外参考时钟 10 MHz、采样率、12-bit WSP 模式
     - 配置输出路径（DC/AC/DAC）与幅度
     - 删除/定义 segment
     - 按 523200 样点分块 IEEE binblock 下载 int16 波形
     - 选择 segment、打开输出、INIT:IMM 启动
  6. 命令行参数支持：--host、--port、-f、--sample-rate、--amplitude、--route、--config-txt。

输出路径注释（已在代码中写明）：
  - "DC"  : DC 耦合放大输出（基带/DMT 常用，默认）
  - "AC"  : AC 耦合放大输出（隔直，射频/IF 常用）
  - "DAC" : 直接 DAC 输出（未经放大，幅度最小）

--- 追加修改（同一会话） ---
时间: 2026-07-31 16:3x

用户反馈：
1. rx_spectrum 频域不对，似乎是仿真信道而不是实测信道。
2. 比特加载结果不对，根本原因是 SNR 估计错误，怀疑把对数值当作了线性值。

问题定位与修改：
1. SNR 公式与 MATLAB 不一致。
   - 原 Python: SNR = mean(|out2|^2) / mean(|out2 - in|^2)
   - MATLAB:    SNR = mean(|in|^2)   / mean(|out2 - in|^2)   (1/EVM^2)
   - 已修改为 MATLAB 公式，sig_pow 使用 in_denorm 的功率。

2. 频谱纵轴与 MATLAB 不一致。
   - 原 Python: 20*log10(abs(fft(sig)))
   - MATLAB:    10*log10(abs(fft(sig)))
   - 已修改 utils.py plot_spectrum 与 plot_adapter.py 中的 _SPECTRUM_TEMPLATE。

3. 无法区分仿真/实测。
   - main.py step2 / step4 增加 rx_source 跟踪：
     * "measured_online"   : 在线示波器采集
     * "measured_offline"  : 离线读取已有文件
     * "virtual_channel"   : 虚拟信道生成
   - 所有 RX 相关图像标题均带上 [rx_source]。
   - 使用虚拟信道时，自动保存波形到：
       data/rxdata/virtual_QPSK_SNRest_{run_id}.txt
       data/rxdata/virtual_DMT_bitloading_{run_id}.txt

验证：
  python -m py_compile dmt_core.py main.py utils.py plot_adapter.py -> 通过
  虚拟信道测试：
    旧公式 mean SNR = 11.04 linear (10.43 dB)
    新公式 mean SNR = 15.99 linear (12.04 dB)
    与 20 dB 虚拟信道设置相符，不再出现之前 ~0.03 的异常低值。

用户反馈：step2 读取的波形频域上看不到信号，怀疑示波器读取代码有问题。

问题定位：
1. 对比 MATLAB oscrunQPSK.m / oscrunDMT.m 后发现：
   - MATLAB 使用 TCPIP 连接示波器（address_OSC.txt 中的 IP，端口 5025），
     而不是 USB-B。
   - MATLAB 读取的是 CHAN2，而 Python config 中默认是 CHAN1。
     这是导致“看不到信号”的最大可能原因。

修改内容：
1. 新增独立测试脚本 scope_capture_test.py：
   - 支持 --resource 指定 VISA/TCPIP 地址、--usb 自动选择 USB 仪器。
   - 默认通道 CHAN2，与 MATLAB 一致。
   - 采集后保存波形、绘制时域/频域图、打印统计信息（min/max/std/RMS/频谱峰值）。
   - 如果波形 std 极低，会提示 "No signal detected"。

2. 修改 config.py：
   - OSC_VISA_ADDR 默认改为 "TCPIP0::localhost::5025::SOCKET"，并注释说明 USB/TCPIP 两种写法。
   - OSC_CHANNEL 改为 "CHAN2"，与 MATLAB 一致。

3. main.py 中 step2 和 step4 的示波器采集通道与时基已和 MATLAB 一致
   （QPSK 80 us/div，DMT 60 us/div，均用 CHAN2）。
