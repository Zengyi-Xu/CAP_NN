# Changelog

## 2026-09-04 — v0.2.0

### Added

- **Keithley 2400 source-meter control**
  - New `keithley2400_controller.py` driver based on `pyserial`, supporting both physical RS-232 ports and USB-to-RS232 adapters (FTDI / Prolific / CH340 / CP210x).
  - New "⚡ Keithley 2400" tab in `dmt_gui.py` for connect/disconnect, source-mode selection (`voltage` / `current`), output level, compliance, NPLC, output on/off, and live measurement readout.
  - Voltage-source mode is fully supported via `:SOUR:FUNC VOLT`.
  - Output is automatically turned off when the GUI closes.

- **Parameter grid scan (bias vs Vpp)**
  - New `grid_scan.py` automation engine for 2-D sweeps over a Keithley-controlled bias and the AWG output amplitude (`Vpp`).
  - New "🔲 Grid Scan" tab in `dmt_gui.py` to configure the scan range, step size, pipeline mode, and Keithley connection.
  - Supports `step1-4` (full DMT-NN) and `step1-2` (QPSK probing only) modes.
  - Final measurement step (Step 4 for `step1-4`, Step 2 for `step1-2`) can be repeated N times and averaged.
  - Each scan gets its own folder under `data/grid_scans/<scan_id>/` containing:
    - `config.json`
    - `summary.csv`
    - `grid_scan.log`
    - rendered `contour_*.png` plots
    - CodePlot v5-compatible scripts under `codeplot_assets/`
  - The Grid Scan GUI only displays the scan ID, summary table, and contour plots to avoid loading large waveform datasets.

### Changed

- `config.py`: added `K2400_*` defaults and `GRID_SCAN_*` defaults.
- `requirements.txt`: added `pyserial>=3.5`.
- `dmt_gui.py`: now has six tabs; added `Keithley2400Panel` and `GridScanPanel`.

## 2025-08-28

### Added

- **GUI image export**
  - Added "Export Current Image" and "Save All Images" buttons to each plot tab.
  - Images are saved by default to `data/plots/<run_id>/`, with folder names matching the experiment `run_id`.
  - A same-name `.json` metadata file is generated when saving, recording the array names, shapes, dtypes used, and the original `.npz` data path.
  - A confirmation dialog is shown when the target directory/file already exists.

- **GUI plot data export**
  - Added "Export Current Plot Data" and "Export All Plot Data" buttons to each plot tab.
  - Export format is `.xlsx`, with different arrays in different sheets.
  - Complex arrays are split into real/imag columns; 0-D scalars, 1D, and 2D arrays are supported.

- **GUI offline run targeting**
  - The "Run Test" tab supports entering the last six digits of the STEP2 (QPSK) and STEP4 (Bitloading) waveform IDs separately.
  - Supports pasting a full run-id / filename; the stage is automatically recognized and `.txt` / `.json` suffixes are stripped.
  - When running offline, the `run_id` of the source RX waveform file is preferred to keep IDs consistent.

- **GUI parameter control**
  - Parameters such as `RATIO` in `config.py` can be modified and saved directly in the "Run Test" tab parameter panel.

- **Windows taskbar icon**
  - Set an explicit `AppUserModelID` and generated multi-size `.ico` icon, attempting to fix the taskbar still showing the default feather icon.

### Fixed

- Fixed the occasional `tuple index out of range` error when exporting bit/power loading and similar plots:
  - 0-D scalar arrays are handled separately to avoid accessing `arr.shape[0]`.
  - When `bbox_inches="tight"` save fails, it falls back to normal saving.
  - A single array write failure during Excel export no longer causes overall failure; other arrays still export normally.

### Improved

- GUI automatically cleans empty folders under `data/plots/` on startup.
- The experiment dropdown is deduplicated based on `data/records/` and sorted in reverse chronological order; experiments generated by single-step runs are also visible.
- Export/save failure dialogs now show the full traceback for easier diagnosis.
